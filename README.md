# Personal Portfolio

My personal frontend developer portfolio website.

## About

This project was created to showcase my frontend skills, projects, and progress in web development.

## Features

- Responsive design
- Multilanguage support
- SCSS architecture
- Smooth animations
- Projects showcase
- Dark/Light mode (planned)

## Technologies

- HTML5
- SCSS
- JavaScript
- Git & GitHub

## Project Structure

```bash
assets/
css/

```

## Installation

Clone the repository:

````bash
git clone https://github.com/Saidbek191/portfolio.git

Run SCSS watcher:

```bash
sass --watch scss/style.scss:css/style.css
````
