About Me

I’m a frontend developer focused on building modern, responsive, and user-friendly interfaces. With a background in web design since 2018 and over two years of frontend development experience, I enjoy turning ideas and designs into fully functional web applications while paying close attention to pixel-perfect implementation, code quality, performance, and user experience.

I work with HTML, SCSS, JavaScript, and React, applying modern development practices, responsive design principles, and component-based architecture. I use Git in my daily workflow and value clean code, well-structured projects, and maintainable interfaces.

For me, development is not only about how a product looks, but also about how fast, intuitive, and reliable it feels for users. I continuously improve my skills, learn new technologies, and build real-world projects that help me grow as a developer and deepen my understanding of frontend development in practice.
